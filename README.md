# Планировщик учебной недели

Современный веб-планировщик для школьников и студентов: задачи, расписание, календарь, уведомления и матрица Эйзенхауэра.

**Репозиторий:** [github.com/rahimovnodir1199-netizen/-](https://github.com/rahimovnodir1199-netizen/-)

**Сайт (GitHub Pages):** после включения Pages в настройках репозитория — `https://rahimovnodir1199-netizen.github.io/-/`

## Запуск (только frontend)

Откройте в браузере или через локальный сервер:

```bash
cd study-planner/frontend
# Python 3
python -m http.server 8080
# или Node.js
npx serve .
```

Перейдите на `http://localhost:8080`

## Возможности frontend

- **Быстрое добавление задач** — панель «+ Задача», Ctrl+N, Enter в быстром вводе
- **Полная карточка задачи** — название, предмет, описание, дата, время, категория, приоритет
- **50+ предметов** + свои предметы с цветами
- **Школьник / Студент** — выбор при первом входе, пресеты расписания (45 / 90 мин)
- **Планировщик недели** — сетка дней, расписание уроков/пар
- **Календарь**, **фильтры**, **архив**, **поиск** (Ctrl+K)
- **Уведомления** — Notification API (напоминания, дедлайны, уроки)
- **Матрица Эйзенхауэра** — отдельный раздел + компактный блок на главной
- **Тёмная / светлая тема**, glassmorphism, адаптив под телефон
- **Данные в localStorage** — автосохранение, экспорт JSON

## Горячие клавиши

| Клавиша   | Действие              |
|-----------|------------------------|
| Ctrl+K    | Поиск задач           |
| Ctrl+N    | Быстрое добавление    |
| Escape    | Закрыть модальное окно |
